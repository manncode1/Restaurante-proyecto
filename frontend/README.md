# Frontend (Angular)

La guía completa del proyecto está en el [README de la raíz](../README.md).

```powershell
npm install
npm start                    # http://localhost:4200 (con proxy al Apache del 8080)
npm test -- --watch=false    # pruebas una vez
npm run format               # formatea con Prettier
npm run build                # producción: dist/frontend/browser
```
